# 0004. Фронт: Play і Verify

Дата: 2026-11-11. Статус: прийнято (етап 5).

## Стек
- Vite 8 + React 19 + TypeScript, Tailwind 4, компоненти в стилі shadcn/ui (Button, Popover на radix-ui), іконки Lucide, шрифти Fontshare (Boska, Satoshi) self-hosted у `web/public/fonts`.
- 3D: three r186 через React Three Fiber 9 + drei 10, сцена в `web/src/scene` перенесена з концепту `docs/design/sea3d.src.html`. Кораблі Kenney Pirate Kit 2.1 (CC0, `web/public/models/LICENSE-kenney.txt`). Сцена вантажиться ліниво окремим чанком.
- near-api-js 7.4.0, як у сервері; хеші і ed25519 через @noble (без node:crypto).
- Маршрути без роутера: `/` (Play) і `/verify/:id`. Тема одна, денне море з концепту, без перемикача dark/light.

## Як іде партія в браузері
- Ключ ed25519 генерується і лежить у `localStorage` (`brinewar.key.v1`); `POST /api/guest` повертає `p-<16hex>.<контракт>`, фронт перевіряє, що акаунт саме під контрактом гри. Жодного вікна гаманця.
- Розстановка до створення гри (Shuffle), далі `new_game_vs_nauarch` і `commit_board`. Поле і солі пишуться в `localStorage` **до** транзакції під ключем `next`, потім під id гри, тож перезавантаження посеред створення не губить поле.
- `GameSession` (`web/src/game/session.ts`) опитує контракт (1,5 с у бою, 8 с у гавані), чиста функція `nextStep` вирішує: commit, answer з Merkle-доказом, reveal, fire, thinking. Кожна дія має ключ «один раз» (`answer:<гра>:<клітинка>`), тож опитування не шле дублікатів; транзакції одного ключа йдуть по черзі (nonce).
- Рядок Наварха береться з `/api/game/:id/proofs` (тіло відповіді моделі), показується лише текстом і лише для ходів, прийнятих контрактом. Браузер сам перевіряє підпис ed25519 ключем з view `model` контракту; без збігу позначки «signed ✓» немає.
- Розкриття флоту Наварха в сцені лише після того, як браузер перебудував його корінь з розкритих клітинок і солей і переконався, що флот легальний.

## Verify
`/verify/:id` перераховує в браузері кожну відповідь Наварха (доказ проти `root_b` і узгодженість hit/miss), його розкриття і підписи моделі; відповіді гравця позначені «checked by contract» (сервер їх не зберігає). Посилання на explorer будуються лише з валідного base58-хешу і `VITE_EXPLORER_TX_URL`.

## Локальний стенд
`server`: `npm run devstack` піднімає near-sandbox, деплоїть контракт, запускає Наварха з фейковою моделлю (справжні підписи ed25519) і API на `127.0.0.1:${DEV_API_PORT:-8787}`, пише rpc/контракт у `DEV_STACK_FILE`. `web`: `BRINEWAR_API_PROXY=http://127.0.0.1:<порт> VITE_NEAR_RPC_URL=<rpc> VITE_GAME_CONTRACT=brinewar.test.near npm run dev`.

## Межі
- Хто стер `localStorage` посеред гри, не може відповісти з доказом: UI пропонує здатися (`resign`) і почати знову.
- Поле гравця не має резервної копії поза браузером (SPEC 8, вибір білдера: поки ні).
- FPS на справжньому телефоні ще не міряли.
